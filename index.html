short-makers

短视频聚合解析 API · 移植自 short_videos · 部署于 EdgeOne Makers

接口

GET
/api/parse?url=<视频链接>
自动识别平台并解析，返回统一 JSON。
GET
/proxy?proxyurl=<媒体直链>&type=douyin
媒体直链代理，解决抖音/微博 403 防盗链（服务端带 Referer 拉取、跟随 302、流式转发）。

示例

curl "https://a.didyou.lovie.me/api/parse?url=https://www.bilibili.com/video/BV1eXWM6GE6x/"
