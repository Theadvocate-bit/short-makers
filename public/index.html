微博 登录/api/weibo/login/qr · /api/weibo/login/poll?qrid= · /api/weibo/login/password扫码 / 账号密码登录，换取 SUB/SUBP Cookie—✅

      
网易云 登录/api/wyy/login/qr · /poll?key= · /password · /sms/send · /sms/confirm扫码 / 手机号密码 / 短信验证码登录，换取 MUSIC_U Cookie—✅

      
媒体防盗链代理/api/proxy?proxyurl=解决抖音/微博直链 403，支持下载—✅

    

    
所有解析接口返回统一 JSON 结构 {code, msg, data}；Cookie 通过请求头 x-bili-cookie / x-weibo-cookie / x-wyy-cookie（或 ?cookie= 等参数）携带；也可在服务端配置环境变量 BILI_COOKIE / WEIBO_COOKIE / WYY_COOKIE 作为兜底。

  


  
  

    
📖 使用示例

    
GET /api/sv?url=https://v.douyin.com/xxxx/
GET /api/douyin?url=（整段分享文本均可，自动提取链接）
GET /api/bilibili?url=https://b23.tv/xxxx&ver=old
GET /api/wyy?url=https://music.163.com/#/song?id=347230&level=exhigh&type=json
GET /api/proxy?proxyurl=（视频直链，403 时用于代理转发；支持 type=douyin|weibo、download=true）

    
接口均支持 GET / POST（form 或 JSON body 中的 url 字段），并开放 CORS，可直接在前端调用。
