所有接口返回统一 JSON 结构 {code, msg, data}，字段说明见项目 docs/视频解析统一JSON格式3.0.md。

  


  

    
📖 使用示例

    
GET /api/sv?url=https://v.douyin.com/xxxx/
GET /api/douyin?url=（整段分享文本均可，自动提取链接）
GET /api/bilibili?url=https://b23.tv/xxxx&ver=old
GET /api/proxy?proxyurl=（视频直链，403 时用于代理转发；支持 type=douyin|weibo、download=true）

    
接口均支持 GET / POST（form 或 JSON body 中的 url 字段），并开放 CORS，可直接在前端调用。
